# KOZA sunumu

- `KOZA-Sunum.pptx` — düzenlenebilir PowerPoint (22 slayt, bölümler, konuşmacı notları; tema renkleri ve yazı tipleri tek yerden değişir).
- `KOZA-Sunum.pdf` — aynı destenin PDF'i.
- `sunum-uret.js` — desteyi üreten betik (pptxgenjs). Veriler depodaki gerçek sayılardır: test sayıları, altın senaryo dağılımı, yöntem matrisi, karar kaydı. Grafikteki emisyon örneği kurgusal test faktörleriyledir ve slaytta böyle etiketlidir.

Süre planı: yaklaşık 20 dakika anlatım + soru-cevap; her slaydın notunda hedef süre yazılıdır.
